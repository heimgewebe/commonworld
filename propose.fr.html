Que se passe-t-il ensuite ?

La suggestion n'est pas publiée automatiquement. Commonworld vérifie l'identité, les sources, les caractéristiques du Commons, les moyens d'engagement, la précision de l'emplacement, la confidentialité et la fraîcheur. Seulement un dépôt de code d'un référentiel distinctement examiné peut publier une entrée de catalogue.

Visibilité publique : Le chemin d'entrée préféré est un problème GitHub public. N'entrez pas d'adresse e-mail, numéro de téléphone, adresse privée, coordonnées, appartement, toit, routeur ou informations familiales. Votre compte GitHub sert comme le chemin de contact ; Commonworld ne collecte aucun champ de contact supplémentaire.

Sans GitHub, ou si la connexion échoue, vous pouvez télécharger un fichier JSON validé localement. Commonworld ne stocke pas les entrées du formulaire sur un serveur. Pour restaurer un brouillon commencé immédiatement après un changement de publication automatique, il est temporairement placé dans le stockage de session de cette onglet. À la prochaine charge, il est supprimé immédiatement et restauré uniquement s'il n'est plus âgé que cinq minutes.
