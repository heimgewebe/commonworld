# Security policy

## Supported version

Commonworld supports the current public production state on the `main` branch. Historical commits, forks, unofficial deployments and locally modified copies are outside this policy.

## Report a vulnerability privately

Use GitHub Private Vulnerability Reporting:

https://github.com/heimgewebe/commonworld/security/advisories/new

Do not use public issues, pull requests or the Commons proposal form for vulnerability details. Public reports can expose users or make remediation harder.

Include, where possible:

- a concise description and expected impact;
- the affected URL, file or commit;
- reproducible steps or a minimal proof;
- relevant browser, device or environment details;
- a suggested mitigation, if known.

Do not include credentials, personal data or unrelated third-party information. Do not disrupt the service, destroy data, or access more information than necessary to demonstrate the issue.

## Coordination boundary

Maintainers will assess reports according to available capacity. This policy creates no response-time SLA, no bug bounty and no promise of payment. Broad legal safe-harbor commitments are not established by this document.

For ordinary bugs, content corrections and Commons proposals, use the public repository channels instead.
