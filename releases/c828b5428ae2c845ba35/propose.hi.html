आगे क्या होगा

सुझाव स्वचालित रूप से प्रकाशित नहीं होता। Commonworld पहचान, स्रोत, कॉमन्स की विशेषताएँ, भागीदारी के रास्ते, स्थान की सटीकता, गोपनीयता और ताजगी की समीक्षा करता है। केवल अलग से समीक्षा किया गया रिपॉजिटरी कमिट ही किसी कैटलॉग प्रविष्टि को प्रकाशित कर सकता है।

सार्वजनिक दृश्यता: सुझाव जमा करने का पसंदीदा मार्ग सार्वजनिक GitHub इश्यू है। ईमेल पता, फ़ोन नंबर, निजी पता, निर्देशांक, अपार्टमेंट, छत, राउटर या घरेलू जानकारी दर्ज न करें। आपका GitHub खाता संपर्क का माध्यम है; Commonworld कोई अतिरिक्त संपर्क फ़ील्ड नहीं जुटाता।

GitHub के बिना, या यदि नेटवर्क विफल हो जाता है, तो आप स्थानीय रूप से एक मान्य JSON फ़ाइल डाउनलोड कर सकते हैं। Commonworld किसी सर्वर पर फॉर्म इनपुट संग्रहीत नहीं करता है। स्वचालित रिलीज़ परिवर्तन के तुरंत बाद प्रारंभ किए गए ड्राफ्ट को पुनर्स्थापित करने के लिए, इसे अस्थायी रूप से इस टैब के सत्र संग्रहण में रखा जाता है। अगले लोड पर इसे तुरंत हटा दिया जाता है और केवल तभी पुनर्स्थापित किया जाता है जब यह पांच मिनट से अधिक पुराना न हो।

ये पांच विवरण संपादकीय समीक्षा को सीधे कॉमन्स आधार मसौदे के रूप में सुझाव का पुन: उपयोग करने देते हैं। आप अलग-अलग बिंदुओं को छोड़ सकते हैं या स्पष्ट रूप से "अज्ञात / मुझे नहीं पता" चुन सकते हैं। इसमें कोई स्कोर नहीं है और कोई स्वचालित प्रवेश निर्णय नहीं है।
