Que se passe-t-il ensuite ?

La suggestion n'est pas publiée automatiquement. Commonworld vérifie l'identité, les sources, les caractéristiques du commun, les modes d'engagement, la précision de localisation, la confidentialité et l'actualité. Seul un commit de dépôt examiné séparément peut publier une entrée du catalogue.

Visibilité publique : La voie d'admission privilégiée est un ticket GitHub public. Ne saisissez ni adresse e-mail, ni numéro de téléphone, ni adresse privée, ni coordonnées, ni appartement, ni toit, ni routeur, ni informations sur le foyer. Votre compte GitHub sert de voie de contact ; Commonworld ne collecte aucun champ de contact supplémentaire.

Sans GitHub, ou si le réseau échoue, vous pouvez télécharger localement un fichier JSON validé. Commonworld ne stocke pas les données du formulaire sur un serveur. Pour restaurer un brouillon commencé juste avant un changement automatique de version, celui-ci est placé temporairement dans le stockage de session de cet onglet. Au chargement suivant, il est supprimé immédiatement et restauré uniquement s'il date de moins de cinq minutes.
