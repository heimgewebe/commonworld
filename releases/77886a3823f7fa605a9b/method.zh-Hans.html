Commonworld 显示什么

Commonworld 通过一个共享发现界面发布精选的 Commons。 当前的初始目录包含 88 Commons 具有数字和/或公开可映射的存在。这是有限的编辑选择，而不是完整的全球统计数据。

数据和来源

每个条目都有一个稳定的 CommonProject.id，首次目录收录的不可变日期、来源、检索日期、活动信息和策展信息。 JSON 文件与地球视图和文本视图使用的数据事实相同。缺少目录条目并不意味着某个区域中不存在 Commons。

什么算作共同点

Commonworld 将公共资源理解为多人共同使用、维护或开发的可识别资源、基础设施、实践或知识体系。录取需要共享资源、社区、共同实践、规则和责任以及共同利益的主要证据。开源、免费访问、非营利地位、权力下放或许多用户本身是不够的。表格保持开放状态；理由具有约束力且机器可读Commons定义合约.

建议和编辑审查

公共候选人可以通过以下方式准备建议 Commons。 Commonworld 不存储表格。首选的引入路径是公开的 GitHub 问题；或者，生成本地 JSON 文件。建议永远不会自动发布。编辑审查检查身份、主要邻近来源、Commons 特征、参与方式、隐私、位置精度、重复项和新鲜度编辑审查合同和文件入场Commons 基础记录。自 2026 年 7 月 31 日起，新的或经过实质性重新审查的条目需要此记录；较早的条目将在其现有审核日期之前进行追溯审核。已到期的旧条目将获得一次性宽限期，直至 2026 年 8 月 31 日。

地点和隐私

数字 Commons 未分配发明的地图坐标。地理信息可以是精确的、近似的或隐藏的。隐藏位置没有几何形状，也不会根据其他信息重建。

技术操作

该网站在 GitHub 页面上静态运行。 MapLibre 在本地提供服务。底图来自公共 OpenFreeMap 实例，作为非关键尽力而为依赖项，没有声明 SLA。如果地图失败，目录和文本视图仍然可用。

隐私

Commonworld 没有帐户、第一方遥测、cookie 或写入 API。地图请求直接发送至 OpenFreeMap；从技术上讲，IP 地址可能会在那里进行处理并出于安全原因临时记录。

无障碍

提供文本视图、键盘路径、简化运动处理和 no-JavaScript 目录。尚未声明全屏阅读器产品适用性或 WCAG 一致性。
